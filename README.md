# EventHub

A full-stack event management platform built with React, ASP.NET Core, and SQL Server.

## Features
- User authentication with HTTP-only cookies
- Event creation, browsing, and RSVP functionality
- Role-based access control (Attendee, Organizer, Admin)
- Responsive design for all devices
- Docker containerization

## Tech Stack
- **Frontend:** React 18, React Router, Axios
- **Backend:** ASP.NET Core Web API
- **Database:** SQL Server
- **DevOps:** Docker Compose

## Getting Started

### Prerequisites
- Node.js v16+
- .NET 10 SDK
- Docker (optional)

### Installation

```bash
# Frontend
cd frontend
npm install
npm start

# Backend
cd backend
dotnet restore
dotnet run
```

### With Docker
```bash
docker-compose up
```
